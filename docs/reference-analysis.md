## lab/ 结构与关键逻辑

- `engine/types.ts`、`rules.ts`：瓶型、容量、层序、合法倒水及满瓶状态。
- `engine/solver.ts`、`solver.worker.ts`、`solveAsync.ts`：搜索和异步求解。
- `engine/generate.ts`、`scripts/`：关卡生成、难度校准及报告。
- `render/shapes.ts`：瓶身旋转轮廓、内腔半径、切片体积、液面高度与溢出角度。
- `render/materials.ts`：程序化环境高光，玻璃与液体 shader，液体截面。
- `render/vessel.ts`：共用瓶体组件，位移旋转、液面晃动及材质参数更新。
- `render/stage.ts`：相机和动画调度，接近、转移、归位三个倒水阶段。
- `render/fx.ts`：水流、飞溅、气泡、闪光粒子。
- `ui/style.css`：深色背景、漂浮微粒、立体按钮与关卡信息面板。

瓶体由半径随高度变化的轮廓旋转生成。液体保持水平依赖内腔切片体积计算：倾斜平面切割圆截面，以积分得到体积，二分求液面高度。溢出角表给出当前体积对应的倾角。液体 shader 同时处理侧面、水平截面与边缘抗锯齿；玻璃反射来自程序化光照环境。

## 当前实际复用

直接保留并使用 `shapes.ts`、`materials.ts`、`vessel.ts`、`fx.ts`、`palette.ts`，以及组件依赖的 `engine/types.ts`、`engine/rules.ts`。UI 抽取原版配色变量、背景、立体按钮和关卡计数面板样式。没有复制上游关卡、广告、网络服务或字体资源。

`src/view.js` 是适配层：将 390×780 屏幕坐标映射为原版的世界坐标，以原版 24° FOV / 8° 俯视的透视相机保留正确视线、弧形液面和瓶口立体感；瓶堆与操作区共用 `VesselView`。倒水直接适配原版 Stage 的抬起、延迟到达水流、随余量倾斜及以瓶体中点归位的编排，液体体积、倾角、玻璃、水流和粒子使用上游实现。水流起点取实际瓶口世界位置，落点取目标瓶真实液面。

游戏规则仍由本项目 `src/rules.js` 决定，复用的原版规则模块仅满足瓶组件内部依赖，不接管四槽与层叠玩法。

## 本地打开

Vite 配合 `vite-plugin-singlefile` 生成自包含的 `dist/index.html`，不再依赖外部 JS/CSS 文件。已以 `file://` 实测 WebGL 启动和拾取；根开发入口在双击时跳转到发布文件，避免源码模块路径造成空白。

## 第三轮视觉与响应修正

- 原适配器把每个单位拆成一层；现按原版 setContents 合并连续同色液体，满瓶单色只对应一个渲染段。
- 取消遮挡液体的0.65变暗系数，统一使用原调色板和原始亮度；遮挡由位置和交互规则表达。
- 上游 materials.ts 有一处项目定制：取消色层边界的额外深色描线，保留颜色自然衔接、顶部弧形高光及折射观感。
- 从正交相机改为原版透视相机；原版液体背面截面 shader 的视线计算依赖 cameraPosition，正交适配不能准确还原该部分。
- 原版 showCork(true) 在完成后落塞，展示700ms、落塞回弹完全结束后再按本游戏规则消除。
- 液层只在数据引用变化时重建，初始摆放调用 resetMotion 避免虚假的加速度晃动；静止时降到约30次/秒绘制，输入和动画立即唤醒。
- 拾取改为280ms；倒水采用原版0.3–0.42s抬起、0.26+0.13×单位数出水、70ms水流到达延迟、360ms归位。输入使用pointerdown，键盘和程序点击仍可用；不再每次选择都销毁重建整组按钮。
- 帧推进使用真实时间差（最高100ms），避免低帧率下40ms时间上限导致动画被拖长。
- 新主页面可自由选三个关卡；游戏内仅保留返回、重开、四个瓶形虚线槽与必要错误反馈。
